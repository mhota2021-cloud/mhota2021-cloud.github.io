プライバシーポリシー / Privacy Policy

最終更新: 2026-10-21

取得する情報

uec-classroom は、利用者が許可した Google アカウントについて、Google Classroom の授業・課題・お知らせ・配布資料と、Google ドライブ上の添付ファイルを読み取り専用で取得する。

利用方法

取得した情報は、利用者自身の端末と利用者自身の Google ドライブに資料を保存するためだけに使う。認証トークンは利用者の端末内にのみ保存する。

第三者への提供

取得した情報を開発者のサーバーへ送ることはなく、第三者に提供・販売することもない。Google API から受け取ったデータの利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従う。

削除

Google アカウントの「サードパーティ製のアプリとサービス」からアクセス権を取り消し、端末内のトークンファイルを削除すれば、以後の取得は止まる。

English summary

uec-classroom reads, with read-only access, Google Classroom courses, coursework, announcements and materials, and attached Google Drive files of the account that authorizes it. The data is used only to save materials to the user's own device and Google Drive. Tokens are stored only on the user's device. No data is sent to the developer's servers or shared with or sold to third parties. Use of data received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked from the Google Account's third-party apps page. Contact: GitHub Issues of this repository.
