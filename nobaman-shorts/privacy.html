プライバシーポリシー / Privacy Policy

最終更新: 2026-10-21

取得する情報

nobaman-shorts は、利用者が許可した Google アカウントについて、YouTube Data API と YouTube Analytics API から、そのアカウントが持つチャンネルの動画の一覧と、再生数・視聴維持率・高評価数などの統計を読み取り専用で取得する。

利用方法

取得した統計は、利用者自身の Notion のページに書き写し、動画の作り方を見直すためだけに使う。認証トークンは利用者の端末内にのみ保存する。

第三者への提供

取得した情報を開発者のサーバーへ送ることはなく、第三者に提供・販売することもない。書き写し先の Notion は利用者自身のアカウントである。Google API から受け取ったデータの利用は、Google API Services User Data Policy（Limited Use の要件を含む）に従う。

削除

Google アカウントの「サードパーティ製のアプリとサービス」からアクセス権を取り消し、端末内のトークンファイルを削除すれば、以後の取得は止まる。

English summary

nobaman-shorts reads, with read-only access through the YouTube Data API and the YouTube Analytics API, the video list and statistics (views, audience retention, likes and similar metrics) of the channel owned by the account that authorizes it. The statistics are used only to record them in the user's own Notion workspace and to improve the user's videos. Tokens are stored only on the user's device. No data is sent to the developer's servers or shared with or sold to third parties. Use of data received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked from the Google Account's third-party apps page. Contact: GitHub Issues of this repository.
